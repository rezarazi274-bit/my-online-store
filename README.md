# رنگین‌مارکت

فروشگاه نمونه فارسی و راست‌چین، ساخته‌شده با HTML/CSS/JavaScript ساده.

## انتشار با GitHub و Cloudflare Pages
1. فایل `index.html` را در ریشه مخزن GitHub خود بارگذاری کنید.
2. در Cloudflare وارد Workers & Pages شوید.
3. Create application > Pages > Connect to Git را انتخاب کنید.
4. مخزن `my-online-store` را انتخاب کنید.
5. برای سایت HTML ساده، Framework preset را روی `None` بگذارید و Build command را خالی بگذارید.
6. Build output directory را روی `/` قرار دهید و Deploy کنید.

سبد خرید در مرورگر کاربر ذخیره می‌شود. پرداخت آنلاین، مدیریت موجودی و ثبت سفارش سمت سرور در این نسخه فعال نیستند.
